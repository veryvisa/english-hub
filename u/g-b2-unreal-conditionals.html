Unreal and mixed conditionals 非真实条件句与混合条件句

If I have time, I'll call you. 我有空就给你打电话。
Real and possible.真实、可能发生。
If I had time, I'd call you. 我要是有空就给你打了。
Unreal now: I do not have time.与现在事实相反：我没空。
If I'd had time, I would have called you. 我当时要是有空就给你打了。
Unreal in the past: I did not call.与过去事实相反：没打。

📏 The rule规则

📏 The rule in one line规则一句话
In unreal conditionals the verb steps one tense back to show distance from reality: past form for an unreal present, past perfect for an unreal past. Mix the two halves when the times differ.虚拟条件句把动词往过去退一步，表示和事实有距离：用过去式说「现在不是这样」，用过去完成式说「当时没发生」。两半时间不同就混着用。

Chinese shows unreality with context or with words like yaoshi (if) and zao zhidao (had I known). English shows it on the verb. The past form in If I had more time is not about the past at all. It signals that I do not have more time.

中文靠语境或「要是」「早知道」表示假设，英语把假设标在动词上。If I had more time 里的过去式和过去无关，它表示「我其实没有更多时间」。

Unreal present or future: if + past, would + verb. If I lived closer, I would walk to work. I do not live closer. Use were for all persons in careful English: If I were you.

与现在或将来的事实相反：if 加过去式，主句 would 加动词原形。正式一点的英语里各人称都用 were。

Unreal past: if + past perfect, would have + past participle. If I had left earlier, I would have caught the train. I did not leave earlier and I missed it. This pattern is how English expresses regret and relief.

与过去的事实相反：if 加过去完成式，主句 would have 加过去分词。英语里的后悔和庆幸都靠这个句型。

Mixed conditionals join an unreal past to an unreal present. Past cause, present result: If I had studied medicine, I would be a doctor now. Present cause, past result: If I spoke French, I would have applied for that job in Montreal.

混合条件句把过去和现在接起来。过去的原因、现在的结果：要是当年学了医，我现在就是医生。现在的原因、过去的结果：要是我会法语，当时就申请蒙特利尔那份工作了。

would belongs in the result clause, not in the if clause. could and might can replace would to show ability or lower certainty: If we had booked earlier, we might have got a better price.

would 只放在结果句里，不放在 if 从句里。could 和 might 可以替换 would，表示能力或把握较小。

Two exceptions you will meet. would can appear in an if clause when it means "be willing" or makes a polite request: If you would wait here, I'll get her. And many speakers say if I was in conversation; if I were is still the form to write, and If I were you is a fixed phrase worth keeping as it is.

会碰到两种例外。would 表示「愿意」或客气请求时可以放进 if 从句：If you would wait here, I'll get her。另外很多人口语里说 if I was；书面仍写 if I were；If I were you 当固定说法整块记。

Examples例句

  • If I were you, I would talk to the landlord first. 我要是你，会先找房东谈。
    Advice: I am not you.提建议：我不是你。
  • If we had a car, we could visit the lake on weekends. 要是有车，我们周末就能去湖边了。
    We do not have a car.我们没有车。
  • If I had known about the deadline, I would have applied. 我要是知道截止日期，就申请了。
    I did not know, so I did not apply.当时不知道，所以没申请。
  • If she hadn't moved to Canada, she wouldn't speak English so well now. 她要是没搬到加拿大，现在英语不会这么好。
    Past cause, present result.过去的原因，现在的结果。
  • If he were more organised, he wouldn't have missed the flight. 他要是做事更有条理，就不会误机了。
    A permanent trait explains one past event.用一贯的性格解释过去的一件事。
  • I would have called you if my phone hadn't died. 要不是手机没电了，我就给你打电话了。
    The if clause can come second; then no comma.if 从句可以放后面，这时不加逗号。
  • If we had left ten minutes later, we might have been in that accident. 我们要是晚走十分钟，可能就赶上那场事故了。
    Relief, with might for an uncertain result.庆幸；might 表示结果不确定。
  • If it weren't so late, I'd stay for another coffee. 要不是这么晚了，我就留下再喝杯咖啡。
    It is late, so I am leaving.现在很晚，所以要走。
  • What would you do if the bank made the same mistake again? 要是银行再犯同样的错，你会怎么办？
    An imagined future, not a plan.假想的将来，不是计划。
  • If I hadn't asked, they would never have told me. 要不是我问，他们永远不会告诉我。
    I did ask.事实上我问了。
  • We could have taken the train if the station had been open. 车站要是开着，我们本来可以坐火车的。
    could have: possible then, but it did not happen.could have：当时可能，但没有发生。
  • If you had taken your medicine, you wouldn't be in bed now. 你要是吃了药，现在就不会躺在床上了。
    Past cause, present result.过去的原因，现在的结果。
  • If I weren't so stubborn, I might have listened to her. 我要不是这么固执，当时也许就听她的了。
    A lasting trait and one past result.一贯的性格，过去的一次结果。
  • I wish I'd kept the receipt; they would have given me my money back. 真后悔没留收据，不然他们就退钱给我了。
    The if clause is understood: if I had kept it.省略了 if 从句：要是留了的话。

More pairs: same idea, different choice更多对比句组

If I had taken that job, I would be in Toronto now. 我当初要是接了那份工作，现在就在多伦多了。
Past condition, present result.过去的条件，现在的结果。
If I spoke French, I would have applied. 我要是会法语，当时就申请了。
Present condition, past result.现在的条件，过去的结果。
Had I known, I would have said something. 早知道我就说了。
The same meaning without if: formal.同样的意思，省去 if，更正式。
If he calls, tell him I'm out. 他要是打来，就说我不在。
He may well call.他很可能会打来。
If he called, I'd tell him the truth. 他要是打来，我就说实话。
I don't expect him to call.我不觉得他会打来。
If he were to call, what would you say? 万一他真打来，你怎么说？
More distant and a little more formal.可能性更小，语气也稍正式。

⚠️ Common slips for Chinese speakers华人常错

✗ If I am you, I will take the offer.
✓ If I were you, I would take the offer.
I can never be you, so the condition is unreal.
我不可能是你，所以是虚拟条件。
✗ If I would have more time, I would learn French.
✓ If I had more time, I would learn French.
would does not go in the if clause.
if 从句里不用 would。
✗ If I knew it yesterday, I would tell you.
✓ If I had known yesterday, I would have told you.
An unreal past needs the past perfect and would have.
与过去事实相反要用过去完成式和 would have。
✗ If I didn't come to Canada, I am still working in a bank now.
✓ If I hadn't come to Canada, I would still be working in a bank now.
Past cause with present result: past perfect, then would + verb.
过去的原因加现在的结果：过去完成式配 would 加动词原形。
