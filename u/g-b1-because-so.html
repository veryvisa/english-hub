One linker per sentence: although, because, so 一句一个连接词

Choose exactly one connector per clause pair, so that although, because and so are never stacked in the doubled way a literal translation from Chinese produces. 每个句子只选一个连接词，避免把中文的“因为……所以……”“虽然……但是……”直译成英语的双重连接。

B1 · CELPIP 5–6⏱ 25 minG06 although...but, because...so used together关联词成对出现

👀 Look first: what changes?先看对比：差在哪里

Read the sentences and decide what each one tells you. Then open the notes.先读这几句，自己判断各自传达了什么，再点开看注解。

Because the bridge was closed, we took a longer route. 因为桥封了，我们走了一条更远的路。
The reason comes first and is presented as the background the listener needs before hearing the result.原因在前，作为听话人需要先了解的背景，再说结果。
We took a longer route because the bridge was closed. 我们走了一条更远的路，因为桥封了。
The result is the main news and the reason is added afterwards as an explanation.结果是主要信息，原因是随后补充的解释。
The bridge was closed, so we took a longer route. 桥封了，所以我们走了一条更远的路。
Two equal clauses in a chain of events, with the result stressed slightly more than the reason.两个并列分句，按事件顺序展开，稍微更突出结果。
Since the bridge was closed, we took a longer route. 既然桥封了，我们走了一条更远的路。
The reason is treated as already known to everyone involved.把原因当作大家都已经知道的事实。

📏 The rule规则

📏 The rule in one line规则一句话
English marks the relationship between two clauses once, with a single connector, and never repeats it on the other clause.英语里两个分句之间的逻辑关系只标记一次，只用一个连接词，另一个分句不再重复。

📖 Why, and when细讲：为什么、什么时候用

Open the full explanation: 6 points, 23 examples展开细讲：6 段讲解、23 个例句

Chinese often marks a cause-and-effect pair at both ends, with one word meaning 'because' at the start and one meaning 'so' in the second half. English treats this as redundant. Choose the side you want to emphasise: if the reason is the news, put because on the reason clause; if the result is the news, put so on the result clause. Never use both in the same sentence.

中文常常两头都标记因果，前面一个“因为”，后面一个“所以”。英语认为这是多余的。你想强调哪一边就用哪个词：如果原因是重点，就把 because 放在原因分句上；如果结果是重点，就把 so 放在结果分句上。同一个句子里不能两个都用。

The same logic applies to concession. The Chinese pattern pairs a word meaning 'although' with a word meaning 'but'. In English, although already creates the contrast, so adding but afterwards makes the sentence ungrammatical in standard writing. If you prefer to start with the main idea, drop although and use but alone, or use however in a new sentence.

让步关系也是同样的道理。中文习惯用“虽然……但是……”成对出现。英语里 although 本身已经建立了对比，后面再加 but 在标准写作中是错的。如果你想先说主要意思，就去掉 although，只用 but，或者另起一句用 however。

Because and so are not just mirror images, they change the order of information. Because lets you start with the result and add the reason afterwards, which sounds natural in speech: 'I stayed home because it was raining.' So forces the reason to come first: 'It was raining, so I stayed home.' Pick the order that matches what the listener already knows.

because 和 so 不只是互为镜像，它们会改变信息的顺序。because 可以先说结果再补充原因，口语里很自然：“I stayed home because it was raining.” 而 so 要求原因在前：“It was raining, so I stayed home.” 请根据听话人已经知道什么来选择顺序。

A because clause on its own is not a complete sentence. Learners often answer a why-question with a single clause starting with because and then add a result clause as a second sentence, or write 'Because I was tired.' as a full written sentence. In formal writing, attach the because clause to a main clause. In spoken answers to a why-question, a bare because clause is acceptable.

单独的 because 从句不是完整的句子。学习者常常用 because 开头写一个从句，然后另起一句，或者在书面语里把“Because I was tired.”当成完整句子。正式写作中要把 because 从句接在主句上；口语里回答 why 问题时，只说 because 从句是可以的。

Be careful with the punctuation of so. It joins two independent clauses, so it normally takes a comma before it: 'The train was late, so we missed the meeting.' A because clause that comes second usually takes no comma. Putting a comma before because is not a disaster, but doing it habitually signals that you are translating punctuation from another language.

注意 so 的标点。它连接两个独立分句，所以前面通常要加逗号：“The train was late, so we missed the meeting.” 放在后面的 because 从句通常不加逗号。在 because 前面加逗号不算严重错误，但如果习惯性地这样写，就说明你在照搬中文的标点习惯。

Since and as can replace because when the reason is already known to the reader, but they do not change the one-connector rule. Do not write 'Since it was late, so we left.' Use since at the start for known reasons, or use so for a new result, but not both together.

当原因是读者已经知道的信息时，since 和 as 可以代替 because，但一个连接词的规则不变。不要写“Since it was late, so we left.” 已知原因用 since 放在句首，新的结果用 so，两者不能同时用。

Examples例句

  • I stayed home because it was raining. 我待在家里，因为在下雨。
  • It was raining, so I stayed home. 在下雨，所以我待在家里。
  • Although the exam was difficult, most students passed. 虽然考试很难，大多数学生还是通过了。
  • The exam was difficult, but most students passed. 考试很难，但大多数学生通过了。
  • She missed the bus because she left home late. 她错过了公交车，因为她很晚才出门。
  • She left home late, so she missed the bus. 她很晚才出门，所以错过了公交车。
  • Because the traffic was heavy, we arrived an hour late. 因为交通拥堵，我们迟到了一个小时。
  • Although he is only twenty, he already runs his own company. 虽然他才二十岁，但他已经经营着自己的公司了。
  • I didn't buy the jacket because it was too expensive. 我没买那件夹克，因为太贵了。
  • The jacket was too expensive, so I didn't buy it. 那件夹克太贵了，所以我没买。
  • We cancelled the picnic because the forecast looked bad. 我们取消了野餐，因为天气预报不太好。
  • Although I was exhausted, I finished the report. 虽然我筋疲力尽，我还是完成了报告。
  • He speaks quietly, so people often ask him to repeat himself. 他说话声音小，所以别人经常请他重复。
  • Since you already know the answer, there is no need to ask me. 既然你已经知道答案，就不必问我了。
  • The restaurant was full, so we went to the café next door. 餐厅满了，所以我们去了隔壁的咖啡馆。
  • I like the apartment, although the kitchen is tiny. 我喜欢这套公寓，尽管厨房很小。
  • My phone died because I forgot to charge it. 我的手机没电了，因为我忘了充电。
  • I forgot to charge my phone, so it died during the call. 我忘了给手机充电，所以通话时它没电了。
  • Although prices have risen, many people still prefer to shop in person. 尽管价格上涨了，许多人仍然喜欢亲自去店里买东西。
  • They moved to Vancouver because her job was there. 他们搬到了温哥华，因为她的工作在那里。
  • Her job was in Vancouver, so they moved there. 她的工作在温哥华，所以他们搬到了那里。
  • He didn't answer the phone because he was driving. 他没接电话，因为他在开车。
  • The hotel was cheap, but the service was terrible. 酒店很便宜，但服务很糟糕。

More pairs: same idea, different choice更多对比句组

Although the film was long, I enjoyed it. 虽然电影很长，我还是很喜欢。
The unexpected positive result is the main point, and the long length is acknowledged first.出人意料的正面结果是重点，先承认电影很长这个事实。
I enjoyed the film, although it was long. 我很喜欢这部电影，尽管它很长。
The opinion comes first and the drawback is added as an afterthought.先说看法，缺点作为补充随后带出。
The film was long, but I enjoyed it. 电影很长，但我很喜欢。
A plain, balanced contrast with equal weight on both halves and a more conversational tone.平实的对比，两部分分量相当，语气更口语化。
The film was long. However, I enjoyed it. 电影很长。不过，我很喜欢。
A more formal and deliberate contrast, split into two sentences for emphasis.更正式、更有意为之的对比，分成两句来加强语气。

⚠️ Common slips for Chinese speakers华人常错

✗ Because it was raining, so I stayed home.
✓ Because it was raining, I stayed home.
Learners translate the Chinese paired pattern literally and keep both a cause word and a result word. English needs only one connector, so remove the second one.
学习者直译了中文的“因为……所以……”结构，把原因词和结果词都保留了。英语只需要一个连接词，去掉第二个。
✗ Although he was tired, but he kept working.
✓ Although he was tired, he kept working.
Although already expresses the contrast, so adding but is redundant. This is a direct copy of the Chinese pairing of a concession word with a contrast word.
although 本身已经表达了对比，再加 but 是多余的。这是对中文“虽然……但是……”搭配的直接照搬。
✗ I was very tired. Because I worked all night.
✓ I was very tired because I worked all night.
A because clause cannot stand alone as a written sentence. Attach it to the main clause, because it only explains that clause.
because 从句在书面语里不能单独成句，要和主句连在一起，因为它只是对主句的解释。
✗ He was late, because of he missed the train.
✓ He was late because he missed the train.
Because of must be followed by a noun phrase, while because introduces a full clause with a subject and verb. Learners mix the two forms and also add an unnecessary comma.
because of 后面接名词短语，而 because 后面接带主语和谓语的完整从句。学习者常常把两者混在一起，还多加了逗号。
✗ It was cold, so that we stayed inside.
✓ It was cold, so we stayed inside.
So that introduces a purpose clause, such as 'We left early so that we could avoid traffic'. For a simple result, use so alone after a comma.
so that 引导的是目的状语从句，例如“We left early so that we could avoid traffic”。表示简单的结果，只用逗号加 so 即可。
