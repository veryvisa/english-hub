📖 Why, and when细讲：为什么、什么时候用

Open the full explanation: 5 points展开细讲：5 段讲解

Chinese learners often avoid phrasal verbs and reach for the "big word" learned for exams: postpone, investigate, tolerate. The result is correct English that sounds stiff, and a listening problem: colleagues say put off, look into and put up with all day.

华人学习者常回避短语动词，用考试背来的「大词」。结果是英语没错却显得僵硬，听力也吃亏：同事们整天说的是短语动词。

Three patterns cover most of them. No object: Something came up. Separable: set up a meeting / set a meeting up / set it up (a pronoun must go in the middle). Inseparable: deal with it, run into a problem (the object always comes after).

三种句型覆盖大多数情况：不带宾语；可分（代词必须放中间）；不可分（宾语永远在后面）。

The particle usually carries stress when it comes last: Let's sort it OUT. If you stress only the verb, a listener may not hear the phrasal verb at all.

小品词在句末时通常重读。只重读动词，对方可能听不出这是个短语动词。

Many have a one-word partner for formal writing. Learn them in pairs so that you can move up or down in register: put off / postpone, turn down / decline, point out / indicate, set up / establish, come up with / devise.

许多短语动词有一个正式的单词对应。成对记，就能按场合升降语域。

Meaning is not always visible from the parts. take on is "accept work", bring up is "mention", run into is "meet by chance". Learn each with a typical object: take on a project, bring up an issue.

意思不一定看得出来，所以要连同典型宾语一起记。

⚠️ Common slips for Chinese speakers华人常错

✗ Let's set up it for Monday.
✓ Let's set it up for Monday.
With a separable verb, a pronoun goes in the middle.
可分短语动词的代词宾语必须放中间。
✗ We need to deal the problem with.
✓ We need to deal with the problem.
deal with is inseparable.
deal with 不可分。
✗ I will follow up the client tomorrow.
✓ I will follow up with the client tomorrow.
follow up with a person, follow up on a matter.
对人用 follow up with，对事用 follow up on。
✗ He came up a good idea.
✓ He came up with a good idea.
Three parts: come up with.
是三个词：come up with。
