vector noun

US /ˈvɛktɚ/ UK /ˈvɛktə/ NAWL · band 1 · #28

a quantity that has both size and direction; an insect or animal that carries a disease 矢量，向量；（疾病的）传播媒介

Forms词形: vectors

How it is used怎么用

Two unrelated fields use the word. In maths and physics a vector has size and direction, unlike a plain number. In medicine a vector is the carrier that passes a disease on: mosquitoes are the vector for malaria.两个不相干的领域都用这个词。数学、物理里，vector 有大小也有方向，和单纯的数不同。医学里，vector 是把疾病传给别人的媒介：mosquitoes are the vector for malaria。

Designers also talk about vector graphics, images stored as shapes that stay sharp at any size.设计行业还说 vector graphics（矢量图），即按形状存储、放多大都清晰的图像。

Examples例句 12

  • Mosquitoes are the main vector for several tropical diseases. 蚊子是好几种热带疾病的主要传播媒介。
  • Force is a vector, so you need to state its direction as well as its size. 力是矢量，所以除了大小还要说明方向。
  • Save the logo as vector graphics and it will print cleanly at any size. 把标志存成矢量图，印多大都清晰。
  • Shared towels can act as a vector for skin infections in a gym. 在健身房，共用的毛巾可能成为皮肤感染的传播媒介。
  • Each arrow on the weather map is a vector showing wind speed and direction. 天气图上的每个箭头都是一个矢量，表示风速和风向。
  • Health teams try to control the vector rather than treat each patient after the event. 卫生队伍设法控制传播媒介，而不是等人病了再逐个治疗。

Where it comes from词源与派生

Learned borrowing from Latin vector (“carrier, transporter”), from vehō (“to carry, transport, bear”), also ultimately the root of English vehicle.
