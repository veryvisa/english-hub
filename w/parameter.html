parameter noun

US /pəˈræmətɚ/ UK /pəˈræmɪtə/ NAWL · band 1 · #4

a limit or a fixed value that controls how something can be done or how a system behaves 参数；（常用复数）界限，范围

Forms词形: parameters

How it is used怎么用

In maths and computing a parameter is a value you set before the calculation runs. In everyday formal English the plural means the limits you have to work inside: within the parameters of the budget.在数学和计算机里，parameter 是运算前设定的值；日常的正式英语里常用复数，指「必须待在里面的界限」：within the parameters of the budget。

The stress is on the second syllable. Do not confuse it with perimeter, the edge of an area.重音在第二个音节。别和 perimeter（周界、周长）混了。

Examples例句 11

  • The manager set clear parameters for the project before anyone started work. 开工之前，经理给这个项目划定了清楚的范围。
  • We have to stay within the parameters of the budget we were given. 我们必须在给定的预算范围内行事。
  • Temperature is the key parameter in this experiment. 温度是这个实验的关键参数。
  • Changing one parameter at a time makes it easier to see what went wrong. 一次只改一个参数，更容易看出哪里出了错。
  • The model has millions of parameters, and none of them was written by hand. 这个模型有几百万个参数，没有一个是人手写的。
  • Parents and teenagers often disagree about the parameters of screen time. 屏幕时间的界限该怎么划，父母和青少年常常意见不一。

Where it comes from词源与派生

From French paramètre, from New Latin parametrum (“parameter”), from Ancient Greek παρα- (“beside”) + μέτρον (“measure”).

Derived words派生词: parameterise, parameterize, subparameter, uniparameter, metaparameter, parameterless, hyperparameter, macroparameter, microparameter, multiparameter, rest parameter, superparameter, time parameter, Hapke parameter
